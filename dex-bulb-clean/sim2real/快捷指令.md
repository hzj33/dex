### 3. Quest 重启后恢复 WiFi ADB

Quest 重启后通常不会保留无线 ADB 的 `5555` 端口。如果出现：

```text
failed to connect to '192.168.12.38:5555': Connection refused
```

或 `oculus_reader` 提示：

```text
Device is visible but could not be accessed.
Run `adb devices` to verify that the device is visible and accessible.
```

按下面步骤恢复：

```bash
adb kill-server
adb start-server
adb devices
```

用 USB 线连接 Quest 到电脑，戴上 Quest，在弹窗里允许 USB debugging / RSA 授权。然后确认：

```bash
adb devices
```

需要看到 USB 设备状态为 `device`。如果显示 `unauthorized`，需要重新戴上 Quest 允许调试授权。

开启无线 ADB：

```bash
adb tcpip 5555
```

看到 `restarting in TCP mode port: 5555` 后，可以拔掉 USB 线，再连接 WiFi ADB：

```bash
adb connect 192.168.12.38:5555
adb devices
```

成功时应显示：

```text
192.168.12.38:5555    device
```

如果 Quest 的 WiFi IP 变了，需要把命令和代码里的 `192.168.12.38` 一起换成新 IP。
