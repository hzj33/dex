## Method and interface

The original PAdapt BC+latent loss and Adam3e-4 are retained; only adapt_tconv is trainable. The E003-only teacher_point_tanh flag corrects the point-cloud teacher latent target to match actual frozen PPO actor inputs. The default remains false for legacy students. The exact-target/no-privileged-action test is scripts/test_m24_e003_student_contract.py.

Export takes raw obs[batch,101] and proprio_hist[batch,30,32], includes normalization and middle/ring action masking, and returns normalized16DOF target increments. The final5obs values remain phase/time commands; they are not inferred by PAdapt. Real position-mode gain/phase adaptation is not included in model weights. The old M24 sources from sim2real4736d94 are preserved under driver/sim2real_reference.

Training and each inference phase have their own timeout and command/status receipts. First teacher and student nominal metrics are in the pipeline status/evaluation files; final candidate, visual and real-hand outcomes remain pending. Cloud remainsON; this session did not authorize or perform hardware actions.
