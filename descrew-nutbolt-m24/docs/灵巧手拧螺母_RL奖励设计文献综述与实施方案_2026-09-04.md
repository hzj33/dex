# 执行摘要
> **核心结论** 近年的成功方案不是奖励“手指在动”，而是奖励“在有效接触、正确轴线和安全载荷下产生的有方向旋转或螺纹推进”。最稳妥的第一版是：接触门控旋转进展 + 轻量里程碑/成功 + 延迟加入的稳定与安全成本。

用户提供的种子报告已经抓住了轴向旋转、有效接触、换指、轴线、力矩/能耗和稀疏课程等关键线索。本次检索沿这些关键词和引用链扩展至 2026 年 9 月 4 日，纳入 26 项论文或项目，并明确区分直接螺纹证据、拧盖/旋钮近邻证据和连续旋转方法证据。

直接螺母/螺栓的公开工作仍然少于一般在手旋转，因此奖励设计不能只盯着标题中含 screw 或 nut 的论文。真正成熟、可迁移的细节大量来自 Tac2Motion、Twisting Lids、RMA、RotateIt、AnyRotate 和 PenSpin：角度/角速度必须裁剪，接触最好作为门控，换指需要事件或初始状态课程，稳定惩罚不能一开始就过强。

## 给你当前任务的六条直接答案
**1. 先做固定转轴原语。**把螺母先建成 revolute joint 上的旋钮，验证连续旋转和换指；不要让真实螺纹接触求解同时干扰动作学习。

**2. 主奖励用接触门控的有向角增量。**推荐 r_eff = G_contact × max(0,clip(Δθ_dir/Δθ_ref,−1,1))，没有有效接触或高滑移时不把转角算作主要正奖励。

**3. 接触不要成为可长期刷分的主奖励。**静态“接触手指数”权重过大会得到只夹不转；接触更适合做门控、小权重稳定项或 release→recontact 事件奖励。

**4. 安全项只惩罚超过软阈值的部分。**法向力、电机电流和功耗从零开始持续惩罚会让策略不敢用力；应使用 ReLU(x/x_soft−1)²，并另设硬终止。

**5. 真实螺纹阶段增加螺距一致性。**用 Δz 与 pΔθ/(2π) 的匹配区分真正沿牙推进和原地滑动旋转。

**6. 课程按成功率推进。**先会转，再会换指，再逐渐加入轴偏、滑移、力/电流和真实啮合；不要按固定步数一次性打开全部成本。

# 4 可直接复用的奖励原语库
下面把论文原语改写为统一的工程形式：所有 cost 定义为非负量，在总奖励中统一减去；所有分量先归一化，再调权重。带“本文建议”的项不是某篇论文原公式。

## 4.1 有向旋转进展
> Δθ_dir = s_dir · unwrap(θ_t − θ\_{t−1})
>
> r_prog = clip(Δθ_dir / Δθ_ref, −1, 1)
>
> *s_dir∈{−1,+1} 指定拧紧或拆卸方向。Δθ_ref 是单步合理进展，不是物理极限。*

采用角度差分更容易与累计圈数、里程碑和螺距对应。正向进展可用 best-so-far 累计，避免策略在阈值附近来回摆动刷分。

## 4.2 有效接触质量与门控
> g_i = I(contact_i) · exp(−((F_n,i−F_i\*)/σ_F)^2) · exp(−v_slip,i/σ_S)
>
> G_contact = min(g_thumb, max(g_index, g_middle, g_ring))
>
> r_eff = G_contact · max(0, r_prog)
>
> *核心：没有拇指—对指有效接触，或滑移过大时，转角不算主要正奖励。*

SD-RL 的 I_C 是最简单的二值门控；Tac2Motion 和 VibeAct 提示使用连续抓持质量、滑移幅值与接触新鲜度。DexH13 的三轴点阵正适合做连续 G_contact。

## 4.3 换指与抓持质量
> r_gait = I(support contact maintained) · I(release → recontact at new sector) · max(0,r_prog)
>
> r_grasp = normalize(λ_min(GGᵀ)) \[simulation / privileged critic\]

换指奖励应是事件奖励，而不是“少接触一根手指”本身。只有支撑接触未断、重接触位置沿目标方向前移，并在短时间内产生正向进展时才奖励。

## 4.4 轴线与非目标运动
> c_axis = clip(acos(k_nutᵀk_bolt)/α_ref, 0, 1)
>
> c_offaxis = clip(\|\|ω×k_target\|\|/ω_ref, 0, 1)
>
> c_drift = clip(\|\|v_nut,⊥\|\|/v_ref, 0, 1)

这些成本应乘课程系数 α_t。初期 α_t≈0，策略已经能转动后再增加，直接对应 RotateIt/AnyRotate 的消融结论。

## 4.5 真实螺纹与螺距一致性
> e_helix = \|Δz − s_z·(p/2π)·Δθ_dir\| / e_ref
>
> r_thread = max(0,r_prog) · clip(1−e_helix,0,1)
>
> *本文综合建议，不是原论文公式。乘正向进展，防止静止时因误差小而持续获奖。*
>
> r_axial = clip(s_z·Δz/Δz_ref, −1, 1)

成功条件建议是多条件合取：目标圈数或深度达到、轴线误差小、螺母未掉落，并可选加入末端扭矩/电流或高度窗口。

## 4.6 滑移、触觉力与电流
> v_slip,i = \|\|ΔCoP_i/Δt\|\| + κ\|\|ΔF_tangent,i/Δt\|\|
>
> c_slip = mean_i I(contact_i)·clip(v_slip,i/v_slip,ref,0,1)
>
> c_force = mean_i ReLU(F_n,i/F_soft,i − 1)^2
>
> c_current = mean_j ReLU(\|I_j−I_0,j\|/I_soft,j − 1)^2
>
> τ_j ≈ k_t,j (I_j − I_0,j)

电流不必先做到精确力矩估计才能使用。先标定空载偏置 I_0 和近似比例 k_t，即可用于软过载代价、饱和检测和功耗近似；独立的硬电流/温度保护仍必须保留。

## 4.7 功耗、动作与里程碑
> c_work = clip(Σ_j \|τ_j q̇\_j\|/W_ref,0,1)
>
> c_rate = mean_j ((a_t,j−a\_{t−1,j})/a_rate,ref,j)^2
>
> r_milestone = I(best_angle first crosses k·π/6)
>
> r_success = I(target depth/turns reached ∧ engaged ∧ safe)

里程碑只触发一次；终局奖励应大于数步 shaping 的总量，但不能大到早期所有轨迹几乎等价。

# 5 面向 PaXini DexH13 的推荐环境与奖励
> **推荐总路线** 先做固定轴 nut rotation，确认 finger gait、触觉门控和连续多圈可学；再加入 screw/helical joint 或真实螺纹接触。第一版不要把抓取、对准、啮合、旋转、拆出和放置全部塞进一个随机初态回合。

## 5.1 任务与动作空间
> **•** v0：螺母约束在 revolute joint 上，脚本给定稳定抓持；目标先 30°–90°，再到 1–3 圈。
>
> **•** v1：使用可信 screw joint 或螺纹接触；螺母必须同时产生有向角度和轴向位移。
>
> **•** 动作：13 维相对关节目标，20 Hz；底层采用位置/力限制 PD、动作 EMA 和 rate limit。
>
> **•** 若加入机械臂，先只开放腕部绕轴 1–2 DoF 或小范围 residual，再逐步开放完整 6D。

## 5.2 观测与触觉压缩
Actor 建议使用：13 关节位置、关节速度、上一动作、13 路电机电流、最近 3–5 帧触觉特征。Critic 在仿真中可额外使用螺母角度、轴向深度、轴线、真实接触点、摩擦、质量、螺距与外力。

1140 个三轴点阵不建议第一版直接拼给 MLP。先按 11 个触觉模块或每根手指压缩为：法向合力、切向合力、接触面积、CoP、最大 taxel、压力方差、CoP 速度、切向力变化、接触二值与滑移幅值。60–150 ms 历史足以覆盖换指和滑移变化。

## 5.3 v0 固定转轴奖励
> r_v0 = 4.0 r_eff + 0.5 r_contact + α_t(0.50 r_gait − 0.50 c_axis − 0.60 c_slip − 0.20 c_force − 0.10 c_current − 0.05 c_work − 0.02 c_rate) + 2.0 r_milestone + 15 r_success − 10 I(drop) − 8 I(lost_contact)
>
> **系数说明** 这些是各分量归一化到约 \[−1,1\] 后的初始化建议，不是任何单篇论文的现成配置。4.0 保证有效旋转绝对主导；接触项很小，避免静态夹持刷分；安全成本通过 α_t 从 0 逐渐增加。

| **分量**  | **定义**                    | **建议权重/课程** | **必须监控**      |
|-----------|-----------------------------|-------------------|-------------------|
| r_eff     | G_contact × clipped 正向 Δθ | 4.0               | 有效转角 / 总转角 |
| r_contact | 拇指 + 至少一根对指有效接触 | 0.5→0.3           | 有效接触占比      |
| r_gait    | 安全 release→recontact 事件 | 0→0.5             | 每圈换指事件数    |
| c_axis    | 螺母轴与目标轴误差          | 0→0.5             | 轴偏 P95          |
| c_slip    | CoP / 切向力变化            | 0→0.6             | 滑移时间占比      |
| c_force   | 超过软法向力阈值            | 0.05→0.2          | 力 P95 / 峰值     |
| c_current | 超过软电流阈值              | 0.02→0.1          | 饱和时间占比      |
| c_work    | 近似机械功                  | 0.01→0.05         | 每圈能耗          |
| c_rate    | 动作变化平方                | 0.01→0.02         | 动作 jerk / 抖动  |
| milestone | best angle 每跨 30° 一次    | 2.0               | 里程碑到达率      |
| success   | 目标圈数/角度且安全         | 15                | 回合成功率        |

## 5.4 v1 真实螺纹奖励
> r_v1 = r_v0 + β_t(2.0 r_thread + 1.5 r_axial + 3.0 r_engaged − 1.0 c_lateral) + 30 I(fully_tightened / fully_removed) − 12 I(cross_thread / disengaged)

β_t 从 0 增加到 1。r_engaged 只在进入正确牙位、轴向位置和姿态窗口时触发一次；r_thread 必须与正向角进展相乘。如果螺纹接触求解始终不稳定，保留 DexScrew 路线：RL 只学固定轴原语，真实啮合由示范 BC、残差策略或真机稀疏微调解决。

## 5.5 推荐训练课程
![灵巧手旋拧任务的五阶段训练课程](dexh13_nut_rl_reward_assets/training_curriculum.png)

**0. 稳定初态 + 固定转轴。**只开 r_eff、少量 r_contact、里程碑和 drop/lost-contact；目标 30°–90°。

**1. 连续换指。**目标增加到 1–3 圈，随机初始相位和 4–6 种稳定抓持，加入 r_gait 与 contact freshness。

**2. 稳定与安全。**有效转角和成功率稳定后，再逐步增加轴偏、滑移、力、电流、功耗和平滑；随机摩擦、质量、CoM、PD、时延与外力。

**3. 螺纹啮合。**先从已啮合状态开始，加入 Δz、r_thread 和错牙终止，再把初始状态逐步移到入口。

**4. 完整任务与真机。**用示范 reset 覆盖对准/啮合，蒸馏去掉 actor 特权信息；真机用低力阈值起步，并可用 RL-100 稀疏成功或人类好/坏片段微调。

## 5.6 成功、失败与硬保护
| **类别**  | **条件**                                             | **奖励 / 处理**                  |
|-----------|------------------------------------------------------|----------------------------------|
| 成功      | 目标圈数/深度达到，轴偏/滑移在阈值内并保持 0.2–0.5 s | +15（v0）或 +30（v1），终止      |
| 掉落      | 有效接触全失且 nut 离开工作区                        | −10，立即终止                    |
| 过载      | 任一力/电流超过硬阈值持续 N 帧                       | 安全停机；训练 −10 至 −30        |
| 错牙/脱离 | 螺距误差、横向偏移或轴偏超过硬阈值                   | −12，终止或回退课程              |
| 超时      | 无进展持续 T 秒                                      | 0 或小负值；alive penalty 不宜大 |
| 反向累计  | 反向转角超过允许回退                                 | −2 至 −5；允许换指的小回摆       |

## 5.7 可直接实现的伪代码

```python
# 所有分量先归一化；cost 定义为非负量
dtheta = direction * unwrap(theta - theta_prev)
r_prog = clip(dtheta / dtheta_ref, -1.0, 1.0)

for finger in tactile_fingers:
    contact = Fn[finger] > Fn_min
    force_quality = exp(
        -((Fn[finger] - Fn_target[finger]) / sigma_F) ** 2
    )
    slip = (
        norm(dCoP[finger] / dt)
        + k_shear * norm(dFt[finger] / dt)
    )
    slip_quality = exp(-slip / sigma_slip)
    g[finger] = contact * force_quality * slip_quality

G_contact = min(g[thumb], max(g[index], g[middle], g[ring]))
r_eff = max(0.0, r_prog) * G_contact
r_gait = safe_release_recontact(history, sector_progress=True)

c_axis = clip(axis_error / axis_ref, 0.0, 1.0)
c_slip = mean_contact_slip_cost(slip)
c_force = mean(relu(Fn / Fn_soft - 1.0) ** 2)
c_current = mean(
    relu(abs(current - current_bias) / current_soft - 1.0) ** 2
)
c_work = clip(sum(abs(tau_est * qdot)) / work_ref, 0.0, 1.0)
c_rate = mean(((action - action_prev) / action_rate_ref) ** 2)

r = 4.0 * r_eff + 0.5 * G_contact
r += alpha * (
    0.5 * r_gait
    - 0.5 * c_axis
    - 0.6 * c_slip
    - 0.2 * c_force
    - 0.1 * c_current
    - 0.05 * c_work
    - 0.02 * c_rate
)
r += 2.0 * new_angle_milestone + 15.0 * success
r -= 10.0 * drop + 8.0 * lost_contact

# 真实螺纹阶段
helix_error = (
    abs(dz - direction_z * pitch / (2 * pi) * dtheta) / helix_ref
)
r_thread = max(0.0, r_prog) * clip(1.0 - helix_error, 0.0, 1.0)
r += beta * (
    2.0 * r_thread + 1.5 * r_axial + 3.0 * engagement_bonus
)
```

# 6 调参、消融与评估
## 6.1 先看分量分布，不要横向抄权重
Tac2Motion 的 850、AnyRotate 的 5、RMA 的 20 和 action 的 0.001 不能直接比较，因为它们对应的原始量纲完全不同。建议在随机策略、训练早期和成功策略上记录每项 reward 的均值、标准差、P5/P95 与累计贡献。主进展项应在成功轨迹的正回报中占主导，任何一个正则项都不应在早期完全压过 r_eff。

> **•** r_eff 长期近 0：先查角度方向、unwrap、门控阈值和初始抓持，不要直接把权重放大十倍。
>
> **•** 接触贡献很大但角度不增长：把静态接触改成门控/事件，减少每步接触正奖励。
>
> **•** 轴偏或滑移成本压倒进展：课程太快或归一化参考值太小。
>
> **•** 碰撞甩转：缩小 Δθ_ref、用 best-so-far、接触门控和高角速度软惩罚。

## 6.2 最小消融矩阵
| **实验** | **奖励配置**                        | **回答的问题**             | **核心指标**               |
|----------|-------------------------------------|----------------------------|----------------------------|
| R0       | 仅 clipped Δθ                       | 纯进展能否学会？           | 总转角、掉落率             |
| R1       | R0 + 二值 I_contact 门控            | 触觉是否阻止空转？         | 有效转角比                 |
| R2       | R1 + 连续 G_contact(Fn,Ft,CoP,slip) | 高分辨触觉是否更好？       | 连续圈数、Sim2Real 差      |
| R3       | R2 + 里程碑 / reset 课程            | 是否出现长期 finger gait？ | 换指次数、完成圈数         |
| R4       | R3 + 轴线/滑移课程                  | 是否转得更稳？             | 轴偏 P95、滑移占比         |
| R5       | R4 + 力/电流/功耗                   | 是否更真机友好？           | 峰值力、电流饱和、每圈能耗 |
| R6       | R5 + 螺距一致性                     | 是否真正推进牙纹？         | 深度/圈、错牙率            |
| R7       | DemoStart 稀疏分支                  | 复杂 shaping 是否必要？    | 成功率、样本效率           |

## 6.3 建议统一报告的指标
> **•** 任务：成功率、平均/最大连续圈数、30°/90°/180°/1 圈达成率、目标深度误差。
>
> **•** 真实性：有效转角比、螺距一致性误差、原地空转比例。
>
> **•** 换指：每圈 release→recontact 次数、重接触成功率、失接触恢复时间、各指使用均衡性。
>
> **•** 稳定：轴偏均值/P95、横向漂移、掉落率、反向回退角。
>
> **•** 硬件：每指 Fn/Ft P95、峰值力、13 路电流 P95、饱和时长、每圈估计能耗和动作变化率。
>
> **•** Sim2Real：相同初态上的仿真—真机成功差、转速差、力/电流分布差和滑移事件差。

# 7 常见失败模式与诊断
| **现象**             | **最可能原因**             | **优先修复**                               |
|----------------------|----------------------------|--------------------------------------------|
| 高速碰撞后瞬时转动   | 未裁剪角速度；无接触门控   | clip + G_contactΔθ + 高角速软惩罚          |
| 抓得稳但完全不转     | 稳定/轴偏/功耗成本过早过强 | α_t 从 0 开始；降低静态接触正奖励          |
| 手指永久夹死         | 接触手指数每步正奖励过高   | 接触改为门控；加入安全 release→recontact   |
| 指尖在附近但无扭矩   | 只用 proximity，没用力窗口 | 用 Fn/Ft/滑移构造连续接触质量              |
| 里程碑来回刷分       | 阈值可重复触发             | 用 best-so-far，只奖励首次跨越             |
| 仿真能转、真机空滑   | 摩擦/触觉过理想            | 随机化摩擦/时延；滑移入观测与 reward       |
| 真机电流饱和         | 安全项太弱或底层 PD 太硬   | 软阈值 cost + 硬终止 + gain randomization  |
| 真实螺纹原地转不推进 | 只奖励 θ                   | 加入 Δz、螺距一致性、engagement 与错牙终止 |
| 只在少数初态成功     | reset 分布太窄             | 多相位稳定抓持 + 示范状态 curriculum       |
| 奖励越来越复杂却不升 | 尺度没归一化、项重复       | Text2Touch 式删项消融                      |

# 8 复现优先级与可发表切入点
**1. SD-RL + Tac2Motion。**先实现接触门控的正向角度，再实现 release/recontact。二者最能利用 DexH13 的三轴点阵。

**2. DexScrew。**采用固定转轴抽象，先把“会拧”与“螺纹仿真是否可信”解耦。

**3. AnyRotate + RotateIt。**复现里程碑和延迟稳定项，重点验证“只抓不转”的局部最优。

**4. PenSpin。**重点复现 4–6 个 canonical reset poses，而不是其长杆专用姿态项。

**5. DemoStart。**长时探索失败时，构造示范状态 reset，不继续盲目增加 reward。

**6. VibeAct + SpikeATac。**真机阶段使用点阵剪切、CoP 和接触变化构造滑移与接触新鲜度。

**7. Factory + FORGE。**进入真实螺纹后再借鉴 screw simulation、轴向目标和力预算。

> **最推荐的论文切入点** 在相同 PPO、随机化和初态下比较：① Δθ；② I_contact·Δθ；③ 连续 G_contact(Fn,Ft,CoP,slip)·Δθ。报告有效转角比、连续圈数、换指成功率、力/电流峰值与 Sim2Real 差距。这一消融既对应 Tac2Motion/SD-RL，又充分利用 DexH13 的高分辨率三轴点阵。

# 附录 C 来源与使用限制
本文以用户提供的《用强化学习训练灵巧手完成旋拧/拧螺丝任务：奖励函数设计的近年研究综述》为关键词种子和初步证据框架，并进一步核对 2025—2026 年新增论文。文中的螺距一致性、DexH13 归一化权重和部分滑移定义均明确属于本文综合建议，而不是原论文公式。

论文权重只有在原始分量定义、归一化和控制频率一致时才可复用。本文给出的 DexH13 权重假设各分量已归一化；真机部署前必须保留独立于奖励的力/电流/温度硬保护、急停、动作限幅和人工看护。

> **一句话原则** 不要奖励“手在动”；奖励“在正确接触和正确轴线下产生的任务进展”。先让策略学会转，再让它学会转得稳、转得省、转得像真实螺纹。
